RecipeManager 🍳

#RecipeManager is a simple web application built with Python and Streamlit. It helps users manage their recipes, search for meals, and decide what to cook.

#Features:

1.Add Recipe: Add new recipes with their ingredients, cooking instructions, preparation time, difficulty level, category, and rating.
2.Search Recipes: Find recipes by name or ingredient and filter them by category.
3.View All Recipes: View, edit, and organize all saved recipes.
4.Recipe Ratings: Rate recipes from 1 to 5 stars and sort them by rating.
5.Surprise Me: Get a random recipe suggestion.
6.Smart Shopping List: Select multiple recipes and generate a combined list of their ingredients.
7.CSV Management: Upload recipe data from a CSV file and download the updated recipe collection.

#Technologies used are: Python, Streamlit, Pandas.

#Data Storage: Recipes are stored in a CSV file (recipes.csv). Users can upload an existing CSV file, make changes to their recipes, and download the updated data.
